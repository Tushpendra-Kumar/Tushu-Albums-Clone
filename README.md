## 📌 Overview

A photo album gallery web application designed for showcasing photographic memories and portfolio media with responsive grid layouts and an interactive modal lightbox viewer.

---

## ✨ Key Features

- **Responsive Photo Grid:** Adaptive masonry-style image arrangement that reorganizes on all screen sizes.
- **Interactive Lightbox Modal:** Click any photo to inspect it in full high-resolution with backdrop blur.
- **Smooth Zoom Transitions:** CSS transform hover scaling effects on thumbnails.
- **Category Tags:** Organized albums by events, travel, and creative collections.

---

## 💻 Tech Stack & Architecture

- **Frontend Architecture:** HTML5, CSS3 Grid & Flexbox, JavaScript Event Delegation
